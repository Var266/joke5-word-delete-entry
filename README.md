Entry for the [make.fun bounty "The Word You'd Delete From the Dictionary"](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2): name the one word to erase from the dictionary forever.

## Entry

**defenestration** — the only word for throwing someone out of a window. Delete it, and the language has no way left to describe the act at all.

## Run

```sh
node main.ts
```

This writes the single word to `/output/entry.txt` (14 characters, exactly one word, inside the 77-character gate).
